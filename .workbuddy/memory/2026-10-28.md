## 2026-10-28 凌晨：修复"很多点击不了"

### 根因（两条，都是实测）
1. **可点面积过小**：认错条目 `.ci`、公司时间线 `.trow`、概念原话 `.quote`、分期 `.period`、规则 `.rule` 这些"看起来是卡片"的块只有末尾 11.5px 的「原文 ↗」小字可点，点正文没反应。用户预期是点整条。
2. **定位坐标错段**（更严重）：`extract_content.py` 的 `locate()` 只归一化空白，**不归一化引号**。概念档案写 `'浮存金'`、信件正文是 `“浮存金”`，匹配不上 → 退到邻近段落 → 点进去看到不相干内容，像"没反应"。修前 2-gram 抽查 334/1581 条内容对不上。

### 改法
- `extract_content.py`：加 `QCH` 正则去掉全部引号（`“”‘’"'「」『』`），`norm()` 统一用于 YBLOCKS 建索引、`locate()`、`locate_surface()`
- `index.html`：加 `jumpAttr(loc)` → 生成 `data-jump="#/l/<id>?b=<n>"`；`bind()` 统一处理 `[data-jump]` 点击（内部 `<a>` 优先，`.ent` 加 stopPropagation 防冒泡覆盖）；`go()` 同 hash 时手动 render
- 整块可点覆盖：`.ci`（认错，含年份页那处）/ `.trow`（813 条时间线）/ `.quote`（201 句）/ `.period`（158 期，跳年份页）/ `.rule`（201 条）
- `feat()` 从 `<div data-f>` 改成真 `<a href>`（可中键/复制链接）
- 「原文字对照」按钮：DOM 里没有 `.enw` 时隐藏，避免死键

### 校验
- 新增 `loccheck.js`：按 2-gram 重叠率判"是否同一段落"（逐字比会误报改写引用）。结果 **1581 条：99.1% 高置信 / 0.9% 可用 / 0 可疑**
- clicktest 新增两项断言：`?b=` 深链落地必须有 `id="b<N>"`；`data-jump` 同理
- clicktest 全量 **15,128 次点击 / 220 页 / 0 失败**；smoke 全绿
